🎠 Carrossel de Fotos — Página Inicial

📐 Tamanho correto das fotos:
Largura: 1536 px  |  Altura: 1024 px  |  Proporção: 3:2
Formato: JPG, PNG ou WebP  |  Tamanho máximo: 2 MB por foto
Dica: Use fotos horizontais (paisagem). Fotos verticais serão cortadas.
✅ Como trocar uma foto:
1. Clique em 📷 Escolher Nova Foto no slot desejado
2. Selecione a foto no seu celular ou computador
3. A foto aparece no preview — clique em 💾 Baixar para Salvar
4. Salve o arquivo baixado na pasta images/carrossel/ do GitHub com o mesmo nome do arquivo original
