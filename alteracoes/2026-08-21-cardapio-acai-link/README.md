# Cardápio Açaí Natureon — página interna

O arquivo `cardapio-acai-natureon.html` é um destino interno sem item no menu principal. Ele exibe as 12 páginas do PDF como imagens responsivas em AVIF, com WebP e JPEG como alternativas de compatibilidade.

Na página inicial, somente o título **Açaí Natureon** do hero aponta para esse destino. O botão **Fechar** usa o histórico do navegador para retornar ao ponto anterior; em acesso direto, volta ao hero da página inicial.
