🚀 Iniciar Nova Campanha de 30 Dias

Preencha a data de início e clique em Iniciar Campanha. O sistema irá gerar automaticamente 30 horários aleatórios diversificados entre 11:00 e 20:00 (horário de SP).

Deixe em branco para usar a data de hoje.

📋 Como Testar Sem Esperar o Horário Real

  1. Inicie a campanha com a data de hoje.
  2. No Cloudflare KV (painel → Workers & Pages → KV → PROMO_KV), encontre a chave picole:dia:YYYY-MM-DD do dia atual.
  3. Edite o campo horarioSorteado para um horário já passado (ex: 00:01:00).
  4. Aguarde até 30 segundos para o status mudar para "ativo" no letreiro do robô.
  5. Para forçar imediatamente: abra o console do navegador e execute fetch('https://api.itapolitanacajuru.com.br/api/promocao/picole/status').then(r=>r.json()).then(console.log).

ℹ️ Variáveis de Ambiente Necessárias

  • PROMO_KV — KV namespace (criar no dashboard Cloudflare e atualizar wrangler.toml)
  • ADMIN_PASSWORD_RECORD ou ADMIN_SECRET — senha do painel admin
  • Número WhatsApp da sorveteria — configurável em scripts/itap-picole-promo.js (variável wppNum)
