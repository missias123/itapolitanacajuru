# Pesquisa externa — padrões verificáveis para o site Itapolitana

Data da pesquisa: 2026-08-13.

## Fontes consultadas

1. Baymard Institute — e-commerce UX best practices: https://baymard.com/learn/ecommerce-ux-best-practices
   Achado utilizado: reduzir fricção no checkout, manter o resumo visível e tornar edição/remoção compreensíveis.

2. Profisee — Single Source of Truth: https://profisee.com/blog/single-source-of-truth/
   Achado utilizado: cada dado crítico deve ter uma origem autoritativa para evitar cópias divergentes.

3. MuleSoft — What Is a Single Source of Truth (SSOT): https://www.mulesoft.com/what-is-single-source-of-truth-ssot
   Achado utilizado: consolidar dados de vários pontos em uma localização confiável, evitando inconsistências entre sistemas.

4. Jamezz — Digital ordering for ice cream parlors: https://jamezz.com/industries/ice-cream-parlors
   Achado utilizado: pedidos de sorveteria precisam suportar seleção de sabores, personalização e revisão do pedido.

5. CommerceBuild — Best practices for e-commerce catalog management: https://commercebuild.com/blog/best-practices-for-ecommerce-catalog-management/
   Achado utilizado: categorização consistente facilita catálogo, inventário e conferência operacional.

## Aplicação limitada ao projeto

Essas referências não autorizam inventar produtos, sabores ou preços. Para a Itapolitana, a regra operacional é manter uma única fonte oficial do catálogo, testar a tela real antes de afirmar correção e limitar alterações às páginas autorizadas pelo usuário.
