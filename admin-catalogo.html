Adicionar produto novo manualmente

Preencha SKU, nome e preço para criar um novo registro no cadastro oficial.

Produtos, sabores e embalagens são administrados no mesmo arquivo oficial. Ao editar manualmente nome, tamanho ou preço de um produto, ele é marcado como esgotado automaticamente até você salvar a base; ao esgotar uma embalagem, seus SKUs dependentes ficam indisponíveis no site.

Sessão administrativa protegida

Para publicar alterações no catálogo, faça login no admin-painel.html. O catálogo usa apenas a sessão segura do Worker e não aceita mais token GitHub ou PIN no navegador.
